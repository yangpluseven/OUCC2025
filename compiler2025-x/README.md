## 项目结构说明

- `CMakeLists.txt`：项目的 CMake 构建配置文件。
- `.gitignore`：Git 忽略文件配置。
- `README.md`：项目说明文档。

### 主要目录
- `src/`：主源代码目录。
  - `main.cpp`：主程序入口。
  - `ir/`：中间代码生成与相关实现。
  - `opt/`：优化相关代码。
  - `parser/`：语法分析与抽象语法树相关代码。
  - `riscv/`：RISC-V 相关后端实现。
  - `utils/`：工具类与通用功能实现。
- `runtime/`：运行时库及相关代码。
  - `include/`：运行时头文件。
  - `src/`：运行时源文件。

如需进一步了解各模块功能，请参考对应目录下的 `README.md` 或源代码注释。
